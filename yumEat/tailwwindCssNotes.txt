max-w-96, max-w-[220px]
max-w-3/4
max-w-md
max-w-sm

2. mx-auto → Visual Centering
This is layout psychology.
When something is centered:
It feels important
It becomes the main focus
It improves balance
Without mx-auto, your container would stick to the left.
Note:- If removing mx-auto changes nothing, it means:

The element is already taking full width
 (or is inside something controlling alignment).
Important Rule:
👉 margin: auto works only when the element is NOT full width.

Auto-centering only works if:
✔ The element has a fixed width (or max-width)
✔ Parent is wider than the element
If width = 100% → Nothing to center.

3. flex → Layout Control System
Flexbox is about alignment control.
When you use flex, you are saying:
“I want full control over how children are positioned.”
This is modern UI thinking.

The direct children of a Flex Container (elements with display: flex or display: inline-flex set on them) become flex items.
Continuous runs of text inside flex containers will also become flex items.

4. 4️⃣ justify-between → Space Distribution Strategy
This is a very common UI pattern:
Left item                Right item
Examples:
Logo | Login
Back button | Settings
Title | Action button
It creates natural balance.

Think of it like:
One element anchors left
One anchors right
Space breathes in between

5️⃣ items-center → Vertical Polish
Without this, elements might look slightly off vertically
This ensures:
Text
Icons
Buttons
All align neatly in the middle.
This small detail makes UI look professional instead of amateur
